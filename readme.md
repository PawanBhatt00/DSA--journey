# 🚀 49 Days DSA Preparation Journey

> **One problem. Every day. For 49 days. No excuses.**

This repository documents my **49-Day Placement Preparation Journey**. During this challenge, I will solve at least one Data Structures & Algorithms (DSA) problem every day to improve my problem-solving skills, strengthen my interview preparation, and build consistency.

The solutions in this repository are **automatically synced from LeetCode using the LeetHub extension**, so every solved problem will be pushed directly to GitHub.

---

## 🎯 Goals

- ✅ Solve at least **1 LeetCode problem every day**
- ✅ Complete the challenge without breaking the streak
- ✅ Improve DSA concepts for placements
- ✅ Build consistency and discipline
- ✅ Prepare for coding interviews
